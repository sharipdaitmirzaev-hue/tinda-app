# TINDA Image Downloader

Простая программа для Windows на Python с графическим интерфейсом (tkinter).  
Скачивает фотографии товаров со страниц каталога **METRO** (`https://online.metro-cc.ru/`).

## Возможности

- Вставка ссылки на каталог/поиск METRO
- Обход диапазона страниц через параметр `page` в URL
- Открытие динамических страниц через **Playwright Chromium**
- Медленная прокрутка для подгрузки ленивых изображений
- Скачивание только фотографий товарных карточек
- Фильтрация логотипов, иконок, баннеров, SVG и картинок меньше 250×250
- Выбор самого большого варианта из `srcset`
- Удаление дубликатов по URL и по хешу содержимого
- Сохранение журнала в CSV (`products.csv`)
- Кнопка остановки и индикатор прогресса

## Структура сохранения

```text
downloads/
  metro/
    page_1/
    page_2/
    page_3/
    products.csv
```

Имена файлов: `{название_товара}_p{номер_страницы}_{короткий_хеш}.{расширение}`

Столбцы CSV:

- `site`
- `page`
- `product_name`
- `image_file`
- `image_url`
- `source_page_url`

## Требования

- Windows 10/11
- Python 3.10 или новее
- Интернет

При установке Python отметьте опцию **Add Python to PATH**.

## Установка на Windows

1. Скопируйте папку программы на компьютер.
2. Откройте папку в проводнике.
3. Запустите **`install.bat`** двойным щелчком.
4. Дождитесь окончания:
   - `python -m pip install -r requirements.txt`
   - `python -m playwright install chromium`

Если Windows спросит разрешение, подтвердите запуск.

## Запуск

1. Запустите **`run.bat`** (внутри вызывается `python app.py`).
2. Вставьте ссылку на каталог, например:

```text
https://online.metro-cc.ru/search?q=напитки&category=napitki-105003&page=1
```

3. Укажите **начальную** и **конечную** страницу.
4. Нажмите **«Выбрать папку…»** — туда будет создана структура `downloads/metro/...`.
5. Нажмите **«Скачать фотографии»**.
6. Следите за журналом: какая страница открыта, сколько картинок найдено/сохранено, какие ошибки.
7. При необходимости нажмите **«Остановить»**.

## Важно

- Программа **не обходит CAPTCHA**, авторизацию и ограничения сайта.  
  Если METRO покажет CAPTCHA, загрузка остановится и появится сообщение.
- Ошибка одной картинки не останавливает всю программу.
- Сейчас поддерживается только **METRO**. Другие сайты не добавлены.

## Ручной запуск (если .bat не подходит)

В командной строке из папки программы:

```bat
python -m pip install -r requirements.txt
python -m playwright install chromium
python app.py
```

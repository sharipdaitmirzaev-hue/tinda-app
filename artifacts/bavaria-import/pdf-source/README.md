# Официальный PDF-буклет

Положите сюда файл:

`БУКЛЕТ БАВАРИЯ 2026.pdf`

или смонтируйте его в `/mnt/data/БУКЛЕТ БАВАРИЯ 2026.pdf`.

Затем выполните:

```bash
npm run import:bavaria:pdf-review
```

Скрипт отрендерит страницы, извлечёт текст и обновит evidence/APPROVED с реальными номерами страниц.
